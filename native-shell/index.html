Enter the HTTPS address of your hosted Author's Forge. For local desktop development, http://127.0.0.1:4573 is also allowed.

Platform modes

  • Android / iPhone / iPad: native client → authenticated hosted Forge runtime.
  • Windows / macOS / Linux: native client now; bundled local-runtime sidecar is the desktop standalone target.
  • Chromebook: Android package where supported, plus installable web/PWA and optional Linux power-user lane.
  • PS5: hosted console web lane; no fake native PlayStation package.
