Platform modes

  • Android / iPhone / iPad: native or hosted client → authenticated Forge runtime.
  • Windows / macOS / Linux: native gateway client now; bundled local-runtime sidecar remains the true standalone/offline desktop release target.
  • Chromebook: Android package where supported, plus installable web/PWA and optional Linux power-user lane.
  • PS5: restricted-WebKit compatibility is retained, but direct consumer PS5 access is not marked supported because PS5 has no normal user-launchable browser; a native release would require Sony-authorized distribution.
