Production truth

  • PNG/JPEG are rendered from the actual canvas.
  • GIF uses a native GIF89a file encoder.
  • Stop-motion uses browser MediaRecorder; the file type is chosen only from formats the browser reports as supported.
  • Print invokes the browser's real print/PDF workflow.
  • No design is published or scheduled externally without a separate integration and author action.
