# 002E — Market Statistics + Author-Visible Keyword Finder

## Goal

Make the live 002D research authority useful to an author in Studio. Forge should answer questions such as:

- What children's book niches show strong current signals?
- What comparable books are visible in those niches right now?
- What observable price/rank/review/publication statistics support the conclusion?
- What reader-search keywords fit the proposed book?
- Which seven evidence-backed phrases should I consider for KDP?

## Statistics honesty rule

Forge may report observable statistics only when they are tied to cited current sources. Examples include sampled bestseller/category rank, listed price, review/rating count, publication recency, number of recent sampled titles, and publication-frequency observations.

Forge must not label inferred unit sales, royalties, revenue, or future demand as observed fact. If a provider derives an estimate, it must remain an inference with methodology and limitations; it cannot become a guaranteed-sales claim.

## Author workflow

1. Choose book and marketplace.
2. Ask a market question or use a niche-discovery preset.
3. Forge performs mandatory live web research.
4. Studio presents research date, sources, observable statistics, comparable titles, ranked niches, and ranked keyword candidates.
5. Author selects up to seven relevant keyword phrases.
6. Author explicitly confirms application.
7. Server reloads the saved report by id and applies only evidence-backed selected phrases to durable Publishing metadata.

No client-posted market report can authorize its own evidence. No research run silently changes publication metadata.
