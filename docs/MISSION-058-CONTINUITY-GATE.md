# Mission 058 — Character Continuity Apply Gate

This checkpoint closes the remaining character-continuity safety gap in the governed Studio drafting path.

A generated manuscript proposal now carries deterministic continuity evidence for every character selected by authoritative context assembly. Each anchor binds the proposal to the exact authoritative character profile used during generation by SHA-256 fingerprint and preserves the retrieval reasons that caused the character to enter context.

Before an accepted proposal can mutate manuscript text, Studio re-validates those anchors against current authoritative character state. If a selected character was deleted, moved to another project, or changed after generation, application is refused and the author must generate/review against current continuity instead of silently applying stale prose.

This gate is deliberately conservative: it does not claim semantic contradiction detection from prose. It proves that the character state used to generate the proposal is still current at apply time. Existing stale-scene protection, explicit author approval, Author Voice drift evidence, durable proposal persistence, and Project Brain source provenance remain intact.
