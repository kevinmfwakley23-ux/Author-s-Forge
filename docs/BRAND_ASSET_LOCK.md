# K.I.N.G.S. Author's Forge — Official Brand Asset Lock

The owner-supplied K.I.N.G.S. Author's Forge crest artwork is the canonical visual brand asset for the Forge.

## Locked artwork rule

- Do not redesign, replace, redraw, recolor, simplify, or reinterpret the crest artwork.
- Shipping-size PNGs may be losslessly encoded or downscaled from the locked master for performance, but must preserve the same artwork and composition.
- Use the official artwork strategically in high-visibility identity surfaces: Studio royal shell, launch/gateway surface, installable-app/PWA identity, and other primary Forge entry points.
- Small UI controls may continue to use text or compact symbols where the complete square crest would become illegible; those symbols are not replacements for the canonical logo.
- Android application identity remains `com.authorsforge.app`; integrating the official artwork must not create a new Android package identity.

## Repository asset paths

- `/assets/brand/kings-authors-forge-official-512.png` — canonical shipping/display derivative.
- `/icon-512.png`, `/icon-192.png`, `/icon-maskable-512.png` — installable-app derivatives generated from the same locked artwork.
- `native-shell/kings-authors-forge-official-512.png` — native gateway copy of the same shipping artwork.

The original owner-supplied artwork remains the source of truth for future higher-resolution derivatives.
