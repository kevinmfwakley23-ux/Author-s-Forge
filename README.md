# Author's Forge

AI Authoring Studio — a long-form writing, editing, continuity, illustration, publishing, and marketing workspace designed to be powered by K.I.N.G.S.

## Repository Role

Author's Forge is a standalone product repository. K.I.N.G.S. remains the independent intelligence/workforce operating system that may power Author's Forge through defined interfaces.

## Initial Development Principle

Build the product through small, independently verifiable missions. Each mission should produce a working, testable checkpoint before the next mission begins.

## Initial Mission

Establish the Author's Forge application foundation, project persistence, portable project packaging, and reliable local startup/recovery behavior.

## Status

Foundation repository created. Product implementation begins from the canonical architecture and mission roadmap.
